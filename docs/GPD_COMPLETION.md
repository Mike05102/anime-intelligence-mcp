# GPD 最終完成条件と開発管理

恒久ルール。事業目的は [開発指針](GPD_DEVELOPMENT_CHARTER.md) に従う。下表の10条件を一つの完成目標とし、条件ごとに対象バージョン、証拠、残作業を記録する。状態は実装、隔離検証、本番稼働、実績確認の順に記録する。完成宣言には全条件に照らした同一リリースの統合証拠が必要。

| # | 完成条件 | 現在の証拠と残る条件 |
|---|---|---|
| 1 | 全24カテゴリーの商品を自動収集・更新 | 隔離で識別・配分・保存を確認。全カテゴリーの継続稼働、鮮度、購入可能な供給を計測する。 |
| 2 | 販売業者の自動探索、参加、本人確認、同意、供給 | 承認済みソース巡回、署名同意、認証取込を隔離検証。実ソース、本人確認の運用、地域別供給が必要。 |
| 3 | AIエージェントへの露出拡大 | 公式MCP Registryに従来版32.0.0の掲載を実測。安定版の掲載更新、接続確認、流入の継続計測が必要。 |
| 4 | エージェントの自己登録、認証、検索と購買判断 | MCP、模擬認証、検索、x402を隔離検証。本番Auth設定と外部エージェントの利用開始を確認する。 |
| 5 | 原則管理者不要の取引 | 引き渡し、署名注文・取消、再送を隔離検証。同意済み販売業者の外部注文連携と実成立が必要。 |
| 6 | 情報提供料・仲介手数料、入金と返金の照合 | 署名台帳を使うx402・仲介料照合を隔離検証。正規台帳接続、収益契約、実入金・返金の照合が必要。 |
| 7 | 多言語、多通貨、多地域 | 言語、通貨、配送国を扱う。地域別の税、返品、換算、決済、実取引の検証が必要。 |
| 8 | 実績を使った自動改善 | 探索配分と獲得経路の集計・配分プレビューを隔離検証。実績発行元と自動適用の検証が必要。 |
| 9 | 障害検知、復旧、保護、無料枠管理 | 隔離DBの失敗復旧、保全、容量削減、移行手順を検証。本番容量・物理領域・当期転送と継続稼働の証拠が必要。 |
| 10 | 全体を一つのシステムとして統合検証 | 供給、発見、購買、注文、取消、照合の通し試験あり。同一リリースでの実顧客、実注文、実収益の確認が必要。 |

## 開発の進め方

買い手の獲得と販売業者の接続は並行して進め、両者を商品検索・引き渡しに接続する。注文の確認は販売業者と台帳の接続に依存し、収益の確認は契約済み条件と確定入金に依存する。得られた集計を成長配分へ戻す。データ保護・復旧・無料枠の検証は全工程に適用する。

各回は最新mainと [再開記録](GPD_CONTINUITY.md) を読み、依存が解消した作業を複数エージェントで並行して実装する。変更を通し試験に結合し、合格後も進められる未完了作業を続ける。実行枠に達したら、検証済みコミット、実行コマンド、次の依存と再開点を保存する。重複実行を避け、既存の継続開発タスクで再開する。本番DBの制限がある間も隔離検証は継続する。

## 実運用の接続と承認

| 接続先 | 既存経路と承認境界 |
|---|---|
| 公式MCP Registry、検索 | 公式Registryの公開掲載を照合できる。最新版の提出は稼働版と所有権を確認した既存手動ワークフローの承認が必要。検索は既存サイトマップから取得可能。検索管理サービスへの新規登録は承認が必要。 |
| 販売業者と商品フィード | 既存のMerchant参加・公開JSON読取経路を使用する。情報源の利用条件と無償上限、販売業者本人の同意、運用者の取込承認を確認する。既存eBay Browseは商品発見、既存USDA FoodData Centralは識別付き食品情報に使える。提携業者の権限や同意は各ソースで別途確認する。 |
| Supabase Authと買い手 | 既存プロジェクトを使い、公開登録と本人確認の運用設定を確認する。 |
| 外部注文、Solana、仲介料 | 同意済み販売業者の署名付き注文と既存x402経路を使用する。正式な台帳発行者、受取先、仲介契約、実発注・送金の権限を確認する。 |

無断の勧誘、外部登録、契約、発注、送金、課金、プラン変更を禁止する。承認が必要な事項はまとめて報告し、独立した開発を継続する。本番移行は既存監視結果を使い、12月2日以降にDB 400 MB未満、物理空き、当期無料転送、稼働、権限、保全を確認した時点で継続開発タスクが担当する。

継続開発は既存の10分間隔タスクに一本化する。容量回収前の11月25日〜12月1日と移行後確認用の12月3日〜9日の監視は、実行日が異なる。各監視は実測の提供と既存承認範囲の保守を担当し、デプロイは継続開発タスクのみが担当する。

外部調査と利用条件は [掲載経路台帳](GPD_CHANNEL_RESEARCH.md) と [全24カテゴリーの商品情報源](GPD_SOURCE_RESEARCH.md) を参照する。
