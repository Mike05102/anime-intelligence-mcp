# GPD 事業目的と恒久開発指針

2026-11-25 制定。すべてのバージョンの設計、実装、レビュー、リリース、チャット間の引き継ぎに適用する。

## 目的

初期商用版の対象はANIME INTELLIGENCEのアニメ、フィギュア、関連グッズ。正確な商品識別と、販売条件を比較した購買判断を買い手AIエージェントに提供する。収益源は買い手のx402料金のみ。販売業者の登録・掲載・接続・商品供給は無料とする。既存商品と監査記録を保全する。

## 優先順位と運用条件

1. 商品、決済、収益記録を保護する。無料プランを維持し、容量と転送量の使用実績、復旧可能性、稼働条件を確認する。
2. AIエージェントの発見、無料試用、有料購買判断、x402実入金の独立照合を優先する。販売業者への引き渡しと注文結果は購買品質・成長の指標として追跡する。
3. 実在する販売業者と購入可能な商品を増やし、在庫・納期・配送・価格の証拠を更新する。型番、JAN/EAN/UPC/GTIN、メーカー識別子、バリエーションを照合し、重複や未検証データを件数に含めない。
4. MCP、API、x402でAIが利用できるようにする。決済ネットワーク、通貨、商品代金、買い手のx402料金、過去の監査記録を区別する。注文や課金の確定には買い手の権限と同意、再送時の冪等性が必要。
5. アニメ商品の販売条件を多言語・多通貨・複数地域で扱う。地域別の配送、税、返品、法令上の条件について、不明点は明示する。
6. 観測根拠を持つ自律探索・監視・自己診断を運用する。不要なログを集計・期限管理し、DB 400 MB未満を運用目標とする。無料枠、物理空き容量、移行安全性、稼働条件の確認で本番切替を判断する。有料プランの変更はユーザーの承認を得る。

## 経営指標と証拠

| 指標 | 測定の根拠 |
|---|---|
| 有効商品数・購入可能商品数 | 検証済みの重複排除された商品。購入可能数は検索対象地域で有効・在庫あり・配送可能なオファーを持つ商品の重複排除数。 |
| 正確性・鮮度 | 根拠付き識別率、サンプル監査の誤一致率、情報源別の最終確認時刻と期限超過率。 |
| 接続販売業者数 | 登録、本人確認済み、購入可能なオファーを出している稼働中の販売業者を区別。 |
| 利用AIエージェント数 | 機械用の安定した識別子と期間内の利用。リクエスト数、IP、ウォレット数は別指標。 |
| 購買判断数・購入先への接続数 | 提供済み判断と、追跡可能な引き渡しイベントを区別し、リトライを重複排除。 |
| 取引成立数 | 照合済みの販売業者側注文・契約記録。クリックや購入意向は成立の証拠に使わない。 |
| 決済成功率 | 一意の支払い試行に対する検証済み成功。決済要求やチャレンジは分母に含めない。 |
| 実際の収益・運営費用・利益 | 買い手のx402取引を独立した正式な入金記録と照合する。決済イベントとテストを区別し、照合済みの入金、返金、費用を会計期間と通貨をそろえて集計する。 |
| DB容量・転送量 | DB実測、物理ディスクの空き、組織の当期転送量、増加傾向を確認。 |

計測できない指標は未計測とする。サンプル、見積もり、テスト、記録されたイベント、照合済みの本番実績を区別する。公開情報に認証情報、顧客情報、取引識別子、非公開の本番数値を含めない。
