# 提携先フィードと台帳の定期確認

承認済み商品フィードと署名付き注文・契約・入出金のスナップショットを、同じ回の非公開レビューにまとめる。両方の取得と検証に成功した場合のみ結果を保存する。データベース登録、注文、決済、通知の実行は含まれない。

```sh
node scripts/gpd33_partner_review.mjs <非公開のフィード承認JSON> <非公開の発行者設定JSON> <対象スナップショットUUID> <非公開の出力ディレクトリ>
```

実行ユーザーだけがアクセスできる出力ディレクトリを、フィード承認と台帳設定の組ごとに使う。定期実行環境では、発行者が指定する検証対象UUIDを、フィードや台帳の本文と独立した経路で渡す。取得先と認証の設定は [フィード](GPD_MERCHANT_OFFER_FEED.md) と [台帳照合](GPD_RECONCILIATION.md) を参照。取得回数と転送量を承認範囲で決めてから、既存の実行環境でこのコマンドをスケジュールする。GitHubの公開ログには結果本文を出力しない。

同じディレクトリの処理は同時に1回まで。既存のLinux実行環境とutil-linuxの `flock` を使う。別の実行が続いていれば `review_in_progress` を返し、取得は次回に繰り越す。同じUUIDの完了済みレビューを再取得しない。失敗時は最終ファイルを残さず、同じUUIDで再実行できる。強制終了時もOSがロックを解放し、再実行時に未完了の一時レポートを整理する。ロックの基点となる `.gpd-partner-review.lock` は実行間で保持する。生成したレポートは非公開で扱い、運用者が承認した保管期間に従って管理する。

実際の取得先とスケジュールは未設定。フィードと署名済み台帳の本番取得、手数料の回収、実取引・収益の本番検証は外部の承認済み経路がそろってから行う。
