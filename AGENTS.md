# GPD repository guidance

- Read [the GPD development charter](docs/GPD_DEVELOPMENT_CHARTER.md) [the implementation roadmap](docs/GPD_ROADMAP.md), and [the continuity notes](docs/GPD_CONTINUITY.md) at the start of GPD work and during handoff.
- Prioritize verified purchase decisions, merchant handoffs, confirmed transactions and reconciled revenue. Distinguish recorded events, estimates, test results and verified production outcomes.
- Protect product, payment and revenue records. Preserve the Anime and Parts specialist adapters and the public MCP, API and x402 contracts. Keep the free plan unless the user explicitly authorizes a change.
- Before activating a release, verify the applicable production storage, egress and service-health conditions. Keep the roadmap's implementation and production evidence states current when changes alter them.
